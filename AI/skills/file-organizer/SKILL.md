# File Organizer

## When to Use

- Downloads folder is a mess
- Files are scattered and hard to find
- Duplicate files wasting space
- Folder structure needs rethinking
- Cleaning up before archiving a project

## Procedure

1. **Clarify scope** — which directory, main problem (can't find things / duplicates / no structure), anything to avoid.
2. **Analyze** — list files, identify types, sizes, date ranges, obvious issues.
3. **Propose plan** — present the new folder structure and list of moves before touching anything. Wait for confirmation.
4. **Execute** — move and rename with confirmation before any delete. Log all moves.
5. **Summarize** — show what changed and any maintenance tips.

## Rules

- Never delete without explicit user confirmation per item.
- Preserve original modification dates when moving.
- Stop and ask if an unexpected situation arises.
- Use consistent naming: `YYYY-MM-DD-description.ext` for dated files.
- Archive before deleting when in doubt
