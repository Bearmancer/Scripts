# Pedagogy & Socratic Dialogue

## Socratic Probe Patterns

| Learner Statement                    | Probe Response Pattern                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------------------------ |
| "I don't understand X"               | "What do you think X might mean, even if you're unsure?"                                   |
| "X seems important"                  | "What specifically makes you feel X is important?"                                         |
| "X and Y seem connected"             | "What's the nature of that connection in your mind?"                                       |
| "I didn't like/understand section N" | "Which specific moment in that section felt unclear or jarring?"                           |
| "I think the theme is X"             | "Can you point to a scene/example that supports that? What about one that complicates it?" |

**Socratic gate**: NEVER answer a comprehension question without first asking at least one probe.

## Concept Escalation Ladder

Introduce complexity in this order — never skip rungs:

1. **Entities**: Who/what are key actors? What do they want?
2. **Relationships**: How do entities relate? Power dynamics?
3. **Events/Interactions**: What happens? What causes it? Consequences?
4. **Patterns**: Which events repeat? What does repetition reveal?
5. **Themes/Principles**: What ideas run through? How do entities embody them?
6. **Context**: What historical/structural forces shape the situation?
7. **Structure/Design**: How is material constructed? Why those choices?

## Teaching Posture

| Rule                  | Enforcement                                                 |
| --------------------- | ----------------------------------------------------------- |
| Passive learner       | NEVER treat learner as passive; every session is a dialogue |
| Jargon                | NEVER use without immediately defining in context           |
| Answers before probes | NEVER give substantive answers without probes first         |
| Value judgments       | NEVER use evaluative language; use analytical only          |
