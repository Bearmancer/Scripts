## 2. PostgreSQL Extensions Required

### 2.1 Extensions Needed

| Extension | Purpose | PostgreSQL 18 Included? |
|-----------|---------|------------------------|
| `unaccent` | Accent-insensitive search | ✅ Yes (contrib) |
| `pg_trgm` | Trigram similarity search | ✅ Yes (contrib) |

### 2.2 Registration Approach

In `ScriptsDbContext.OnModelCreating`:

```csharp
protected override void OnModelCreating(ModelBuilder mb)
{
    mb.HasPostgresExtension("unaccent");
    mb.HasPostgresExtension("pg_trgm");
    mb.ApplyConfigurationsFromAssembly(assembly: typeof(ScriptsDbContext).Assembly);
}
```

EF will auto-generate `CREATE EXTENSION IF NOT EXISTS` SQL in migration.

### 2.3 Functional Indexes (Future)

**Npgsql 10.0.1 supports** expression-based functional indexes via raw SQL:

```csharp
migrationBuilder.Sql(
    "CREATE UNIQUE INDEX IF NOT EXISTS ix_artists_name_unaccent ON artists (f_unaccent(name) text_pattern_ops)");

migrationBuilder.Sql(
    "CREATE INDEX IF NOT EXISTS ix_artists_name_trgm ON artists USING gin (name gin_trgm_ops)");

migrationBuilder.Sql(
    "CREATE INDEX IF NOT EXISTS ix_tracks_title_unaccent ON tracks (f_unaccent(title) text_pattern_ops)");
```

**Not yet configured** — can be added in Phase 05 or later.
